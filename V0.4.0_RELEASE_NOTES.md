# VEDA 0.4.0 — Execution Proof and Governed Actuals

## What changed

- Versioned typed source schemas for DPR, welding, NDT, NCR and material registers.
- Per-file relevance classification keeps manuals/reference material out of field-progress evidence.
- The reality graph is part of normal linking and persists multi-activity and new-scope relations.
- Conflicts are durable, idempotent records with explicit human resolution and audit history.
- Coupled proposal groups are approved atomically and published only when every read-back matches.
- Pipeline Welding Execution Proof Contract v1.0 uses DPR + welding + independent NDT; open NCRs block acceptance.
- Actuals Certificates preserve immutable, hash-addressed proof snapshots and limitations.
- Primavera P6 sandbox writes perform read-before-write ownership/type checks and read-after-write verification.
- Voice/text field capture produces an editable extracted-event card before confirmation.
- Demo data is isolated from the working database; verification tools no longer clear the default project table.

## P6 API basis

The adapter follows Oracle Primavera P6 EPPM Release 26 Activity REST behavior:
Activity GET supports explicit `Fields` and `Filter` query parameters; Activity PUT
updates activity fields; and P6 distinguishes Duration, Physical and Units percent
complete. Physical percent may be calculated from weighted Activity Steps, so VEDA
does not silently write Duration Percent Complete to an activity using another basis.
