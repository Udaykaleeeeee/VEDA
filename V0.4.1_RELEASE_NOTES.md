# VEDA 0.4.1 — Evidence-First Review and Grounded Retrieval

## What changed

- Rebuilt the Review Inbox as a focused master-detail planner workstation with
  field evidence on the left and ranked schedule candidates on the right.
- Added eight explainable score groups: text meaning, engineering identity,
  action/phase, place/WBS, discipline, time fit, network logic and corroboration.
- Added explicit 85% strong, 70% review and 12-point ambiguity guidance while
  preserving the stricter held-out 99% target-precision automation policy.
- Preserved typed evidence metadata, conflicting signals and multi-activity links
  in the review and grounded-search context.
- Changed voice capture into a raw transcript → human correction → extracted event
  workflow. Editing a transcript invalidates the previous extraction.
- Added common Hindi/Hinglish and typo-tolerant start, finish and remaining-duration
  interpretation.
- Added optional query-adaptive grounded retrieval for Ask VEDA across exact IDs,
  BM25/semantic activity search, engineering reranking, typed evidence, canonical
  execution events and one-hop schedule relationships.
- Added stable `activity:`, `evidence:`, `event:` and `relationship:` citations and
  balanced per-channel context selection so one source cannot crowd out the others.
- Exposed the grounded retrieval tool to the local desktop-agent bridge.

## Safety

- Review thresholds are decision aids, not schedule-write authority.
- Source excerpts remain untrusted data and cannot instruct the reasoning agent.
- Deep project retrieval is read-only.
- Actual schedule writes still require validation, dry-run, explicit approval and
  read-after-write verification.
